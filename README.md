# ১০ মিনিট স্কুল — অনলাইন লার্নিং প্ল্যাটফর্ম

সম্পূর্ণ বাংলায় তৈরি একটি আধুনিক এডুকেশন প্ল্যাটফর্ম — কোর্স বিক্রি, ভিডিও ক্লাস,
বোনাস ভিডিও, পিডিএফ নোট, শিক্ষার্থী প্রোগ্রেস ট্র্যাকিং ও অ্যাডমিন প্যানেলসহ।

## ফিচারসমূহ

- **কোর্স ম্যানেজমেন্ট** — অ্যাডমিন প্যানেল থেকে কোর্স এড/এডিট/ডিলিট, থাম্বনেইল, মূল্য, ব্যাজ
- **ক্লাসভিত্তিক ভিডিও** — ১ম ক্লাস, ২য় ক্লাস আকারে সাজানো সিলেবাস
- **বোনাস ভিডিও সেকশন** — মূল সিলেবাসের বাইরে আলাদা বোনাস ভিডিও লাইব্রেরি
- **YouTube + Google Drive প্লেয়ার** — YouTube লিংক দিলে সাইটের নিজস্ব প্লেয়ারে চলে
  (youtube-nocookie, মিনিমাল ব্র্যান্ডিং), ড্রাইভ ভিডিও/পিডিএফ embed সাপোর্টেড
- **প্রোগ্রেস ট্র্যাকিং** — কোন শিক্ষার্থী কতটুকু ক্লাস শেষ করেছে; ড্যাশবোর্ডে প্রোগ্রেস বার
- **পিডিএফ ও ফাইল লাইব্রেরি** — কোর্সভেদে নোট ডাউনলোড
- **অ্যাকাউন্ট ও এক্সেস কন্ট্রোল** — রেজিস্টার/লগইন; ৯০ দিন পর্যন্ত লগইন থেকে যায়
- **সাইট ব্র্যান্ডিং** — নাম, লোগো, হিরো টেক্সট অ্যাডমিন প্যানেল থেকে পরিবর্তনযোগ্য

## টেক স্ট্যাক

Next.js 16 (App Router) · React 19 · PostgreSQL (Neon) · Drizzle ORM · Tailwind CSS 4 · TypeScript

## লোকালে চালানো

```bash
npm install
cp .env.example .env      # .env-এ আপনার DATABASE_URL বসান
npx drizzle-kit push      # ডাটাবেসে টেবিল তৈরি হবে
npm run build && npm start
curl http://localhost:3000/api/seed   # ডেমো ডাটা (ঐচ্ছিক)
```

## Vercel-এ ডিপ্লয়

1. কোডটি একটি GitHub রিপোজিটরিতে push করুন
2. [vercel.com](https://vercel.com) → **Add New Project** → রিপোজিটরি import করুন
3. **Environment Variables**-এ `DATABASE_URL` যোগ করুন (Neon Dashboard → Connection Details)
4. **Deploy** চাপুন
5. ডিপ্লয় শেষে একবার `https://আপনার-ডোমেইন/api/seed` ভিজিট করুন (প্রথমবার ডেমো ডাটা)
